# Phase 2 — 15-Minute Demo Route

## Route

**Home Farm ↔ Basin Village ↔ Basin Wilds**

The Village is the mandatory hinge. There is no direct Home Farm ↔ Wilds connection.

## Home Farm

Purpose: home-base payoff and system anchor.

Contains:
- farmhouse visual + collision footprint
- working farm plot
- farm storage
- rest point
- creature assignment/work infrastructure
- placeholder Ledger/payment marker for later phases
- one exit to Basin Village

Wild encounter spawning is disabled here.

## Basin Village

Purpose: compact social and service hub.

Contains:
- Mei
- Ledger Clerk placeholder
- Pao, shopkeeper placeholder
- Tavi, quest-resident placeholder
- working supply stall
- two cottage/office landmarks with collision
- exit west to Home Farm
- exit east to Basin Wilds

Wild encounter spawning is disabled here.

## Basin Wilds

Purpose: exploration/encounter pocket.

Contains:
- one active creature habitat
- painted forage and resource tiles
- river crossing terrain
- quest-clearing / hidden-grove discovery marker
- one exit back to Basin Village

Wild encounter spawning is enabled only here.
