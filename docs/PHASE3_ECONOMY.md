# Phase 3 — Farm, Resource & Selling Loop

## Purpose
Phase 3 proves the first 3–4 minutes of the 15-minute demo without depending on combat, quests, debt, or gambling.

## Player Loop
1. **Harvest** the ready Moonroot on the home plot.
2. **Till** an empty starter plot with the Field Hoe.
3. **Plant** either Moonroot or the demo-fast Sunpod.
4. **Water** the planted crop.
5. **Chop** one Basin Tree to receive Wood + Plant Fiber.
6. **Mine** one Basin Rock to receive River Stone.
7. **Forage** one Wild Herb patch with Interact.
8. **Rest** once. Sunpod becomes harvest-ready after one watered night.
9. **Harvest** Sunpod.
10. Use the **Farm Shipping Stand** and sell carried goods in one click per stack.

## Phase 3 Demo Content

### Tools
- Slot 1 — Field Hoe
- Slot 2 — Watering Can
- Slot 3 — Field Axe
- Slot 4 — Field Pickaxe

### Crops
- **Moonroot** — normal demo crop; one ready specimen is pre-seeded for immediate harvest teaching.
- **Sunpod** — quick showcase crop; one watered night to maturity.

### Basic Resources
- **Basin Wood** — tree drop.
- **Plant Fiber** — bonus tree drop.
- **River Stone** — rock drop.
- **Wild Herb** — interactable forage.

### Economy Targets
The player begins with **40 currency**. A short crop + tree + rock + herb pass should visibly increase that total without requiring repetitive grinding. Tools and seeds have zero sell value so the short demo cannot accidentally sell its required controls.

## Scope Boundary
Phase 3 does **not** add debt, wagers, combat progression, quest rewards, evolution, building expansion, or creature automation changes. Those arrive in later phases.
